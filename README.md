# huii: human - ai interface (WIP)

__This project aims for conceptual implementation, not meant for production-grade__

This project is to make 'AI-friendly, Data-Oriented' programming language, with keeping 'high performance' and 'safety'.

## Usage (MVP)

Currently, the compiler parses files, registers them into the Context Engine, and generates AI triggers.

### Prerequisites
- [Rust](https://www.rust-lang.org/) (Cargo)
